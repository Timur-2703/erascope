# Erascope — бета

Бесплатные игры на чутьё к месту, времени и цене. Сайт статический: одна страница `index.html`, папка `photos/` и файл настроек `config.js`.

## 1. Выложить сайт (5 минут, бесплатно)

**Самый быстрый путь — Netlify Drop**
1. Откройте app.netlify.com/drop и войдите (можно через GitHub).
2. Перетащите в окно всю папку `erascope`.
3. Через минуту будет адрес вида `something.netlify.app`. В Site settings → Change site name его можно сделать понятнее.

**Через GitHub (удобно обновлять)**
1. Создайте на GitHub пустой публичный репозиторий, например `erascope`.
2. Add file → Upload files → перетащите содержимое папки → Commit.
3. Подключите репозиторий в Vercel (vercel.com → Add New → Project) или Cloudflare Pages. Настройки сборки не нужны: это статический сайт.

После выкладки впишите адрес сайта в `SITE_URL` в `config.js`: он добавляется к результату, которым игроки делятся.

## 2. Включить общий рейтинг (10 минут, бесплатно)

1. Зарегистрируйтесь на supabase.com и создайте проект (регион: Frankfurt или ближайший к аудитории).
2. SQL Editor → New query → вставьте содержимое `supabase.sql` → Run.
3. Authentication → Sign In / Providers → включите **Anonymous sign-ins**. Игрокам не нужна регистрация: каждый получает анонимный аккаунт и может задать ник.
4. Project Settings → API: скопируйте **Project URL** и **anon public key** в `config.js` (`SUPABASE_URL`, `SUPABASE_ANON_KEY`). Ключ anon публичный, его можно хранить в коде сайта; доступ к данным ограничен правилами из `supabase.sql`.
5. Загрузите обновлённый `config.js` на хостинг.

Без этих настроек сайт полностью работает, а результаты хранятся на устройстве игрока.

## 3. Обратная связь

Создайте короткую форму в Tally или Google Forms («что сломалось / какая цена неверна / идеи») и вставьте ссылку в `FEEDBACK_URL`. В шапке появится кнопка Feedback.

## 4. Аналитика (по желанию)

Подключите Plausible, Umami или PostHog: вставьте их скрипт перед `</head>` в `index.html`. Главные метрики беты: доля доигравших до конца, возвраты на следующий день, нажатия «Поделиться».

## Что важно знать

- Язык по умолчанию английский, переключатель RU в шапке. Поменять можно в `DEFAULT_LANG`.
- Вызов дня меняется в полночь по UTC и одинаков для всех.
- Рейтинг в бете защищён от явно невозможных очков, но не от продуманной накрутки: результаты считаются на устройстве игрока. Для беты это нормально.
- Все фото и панорамы — Wikimedia Commons и Mapillary под свободными лицензиями. Подписи авторов в игре обязательны по условиям лицензий, не удаляйте их.
